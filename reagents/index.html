Reagents help

Orders searches previous purchases by item name, number or brand. Historical prices are reference information. Confirm the price, vendor and quantity, then apply for purchase. The owner approves requests; approval enables “Proceed to purchase”. Record arrival with the acceptance date and storage position to create an Inventory entry. Email status is shown on each request.

Inventory shows the current sheet's items. “Unverified” means that presence or quantity needs checking. Historical snapshots never add to current stock.

Open an item to edit details or record use. The owner can also view its source and changes. Use quantities retain their original units; the app will not convert or combine incompatible units.

Dangerous chemicals includes source-flagged chemicals, safety records and inspection logs. An unflagged item is not a declaration that it is safe. Verify the supplier SDS and the current TMU requirements before handling.

Export in Inventory and Dangerous chemicals includes all matching items across pages. XLSX downloads an Excel workbook; PDF opens a preview, then the browser’s Print / Save as PDF dialog.

History, original source rows and change history are available only to the owner. Review remains available to the owner and managers.

Changes save directly to the shared database. If someone edits the same record, refresh and review before saving again. Private reagent records are not stored in the browser's offline cache.

Access logs in Settings are visible only to the owner, including when managers can edit records. They show the latest shared-account sign-ins and recorded app activity. Account sign-ins do not identify which app was opened. Failed sign-ins are not included.

Member permissions, source imports and account access are managed by the owner. Importing a source never overwrites an existing edited item silently.
